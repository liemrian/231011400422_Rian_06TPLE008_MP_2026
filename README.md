# Sketsa layout
Saya menggunakan widget Flutter seperti MaterialApp dan Scaffold membagi halaman menjadi AppBar dan body. Bagian AppBar dibuat menggunakan Container dengan LinearGradient, kemuidan di dalamnya terdapat Row, Column, CircleAvatar, dan Text untuk menampilkan identitas pengguna.
Pada bagian body saya menggunakan ListView. Setiap workshop ditampilkan menggunakan widget custom WorkshopCard. Di dalam card digunakan kombinasi widget seperti Container, Row, Column, Icon, Text, dan ElevatedButton

# Alasan pemilihan widget
MaterialApp dan Scaffold dipakai biar struktur aplikasinya rapi, ListView supaya daftar workshop bisa di-scroll kalau datanya nambah banyak, lalu Row dan Column buat ngatur posisi komponen. Container dipakai buat tampilan, Icon biar informasi lebih jelas, dan ElevatedButton buat tombol daftar workshop. Selain itu.

# 2 kesalahan UI
- Tampilan terlalu penuh ahar menghindari menaruh terlalu banyak komponen dalam satu layar karena bisa bikin bingung dan tampilan terlihat penuh.
- Warna dan desain tidak konsisten, menghindari penggunaan warna yang terlalu banyak atau tidak cocok satu sama lain.

# Kenyamanan baca (UX)
Tampilan disusunan yang rapi dan jarak antar komponen yang cukup, jadi layar tidak kelihatan penuh. Warna juga dibuat konsisten supaya enak dilihat, dan ukuran dan font teks dibuat jelas agar informasi gampang dibaca.
